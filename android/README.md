# QuickQR – Complete Android Studio Project
Designed by Jagadeesh
Tagline: Scan Fast. Create Easy.

This directory contains the complete, production-ready Android Studio project built with:
- Kotlin & Jetpack Compose
- Material 3 Design
- CameraX & ML Kit Barcode Scanning
- Room Database (Offline-first)
- ZXing QR Generation
- Google Mobile Ads (AdMob) SDK & UMP SDK
- Bilingual support: English and Telugu (తెలుగు)

See BUILD_INSTRUCTIONS.md for step-by-step setup and APK/AAB build steps.
